# Meeting Notes

This directory stores concise group and supervisor meeting records for the COMP1884 project.

Meeting records are part of the project's accountability, coordination, and group-work evidence.

## File naming

Use one Markdown file per meeting:

```text
YYYY-MM-DD-short-topic.md
```

Examples:

```text
2026-09-20-project-commencement-meeting.md
2026-09-24-supervisor-meeting.md
2026-09-28-group-progress-meeting.md
```

## Required content

Each meeting note should contain:

- date;
- time;
- meeting type;
- purpose;
- attendees;
- topics discussed;
- decisions made;
- actions agreed;
- action owner;
- due date where applicable;
- status;
- blockers;
- related GitHub Issue / Pull Request / Decision Record where available;
- items requiring supervisor/module-leader confirmation.

## Traceability

Where relevant, connect the meeting record to project evidence:

```text
Meeting discussion
    -> decision
    -> GitHub Issue / Decision Record
    -> implementation branch
    -> Pull Request
    -> merged result
```

The notes should record what was actually discussed at the meeting. Later project decisions should not be backdated into an earlier meeting record.
